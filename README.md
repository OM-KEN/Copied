# Copied

智能复制反馈工具——每次复制内容，屏幕顶部弹出精美的 Toast 通知，清晰展示复制内容。不再猜测「到底复制成功了吗」。

**双平台支持：macOS & Windows。**

---

## macOS

[→ Copied-mac 详细文档](Copied-mac/)

macOS 26 原生液态玻璃卡片 UI，SF Symbols 系统图标，纯 Swift + AppKit + SwiftUI。

| 特性 | 说明 |
|------|------|
| 触发方式 | ⌘C |
| 卡片风格 | 液态玻璃（macOS 26 Native） |
| 图标系统 | SF Symbols |
| 技术栈 | Swift + AppKit + SwiftUI |
| 安装 | `./build.sh` → `.build/Copied.app` |
| 下载 | [Copied-mac.dmg](https://github.com/OM-KEN/Copied/releases) |

---

## Windows

[→ Copied-win 详细文档](Copied-win/)

Apple 风格浮动卡片 UI，Material 3 矢量图标，WPF (.NET 8) 单文件应用。

| 特性 | 说明 |
|------|------|
| 触发方式 | Ctrl+C |
| 卡片风格 | Squircle 圆角 + 弹性弹簧动画 |
| 图标系统 | Material 3 Rounded 矢量 Path |
| 主题 | 亮色/暗色，跟随系统或手动指定 |
| 技术栈 | WPF + .NET 8 + C# |
| 安装 | 下载 `Copied.exe` 双击运行（自包含，无需安装 .NET） |
| 下载 | [Copied.exe](https://github.com/OM-KEN/Copied/releases) |
