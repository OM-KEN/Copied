# Copied 设计规范

> 视觉 Token、通用组件和首次引导页规范见 `UI_GUIDELINES.md`；本文继续记录产品行为与交互决策。

## 设计理念

复制完成后，屏幕顶部弹出一张液态玻璃卡片，告诉你复制成功、让你无需移动指针就能操作。折叠态 3 秒后安静消失且不抢焦点；主动展开全文后进入可选文本状态。

## 视觉

**材质**：macOS 26 原生液态玻璃，半透明，自适应亮暗模式。

**排版**：San Francisco，预览 14pt Medium，辅助信息 12pt Medium。系统色（`.primary` / `.secondary`），自动匹配主题。

**卡片**：32pt 平滑圆角，最大宽 360pt，内容自适应。边缘 primary 15% 描边补深度（自适应亮/暗模式）。

**图标**：SF Symbols 32pt。色值复制时显示 32×32 圆角色块（同色调阴影）。文件显示 64×64 缩略图。

## 动效

**入场**：弹簧弹入，卡片从菜单栏下方放大+飞入+去模糊+淡入，0.2→1 缩放，四属性同步，~550ms，2-3 次微弹跳。

**退场**：淡出+模糊，200ms。干脆利落。

**声音反馈**：每次成功读取且通过来源过滤的剪贴板写入均播放系统提示音，默认 Frog、音量 50%；可在通用设置中更换或关闭。设置切换时立即试听。声音先于轻打扰筛选和视觉去重，因此被筛掉的视觉提示、连续复制的相同内容仍有听觉确认；声音载入与播放在专用串行队列执行，不进入窗口显示的主线程关键路径。

## 交互

### 弹窗呈现
- App 启动时用标准 Toast 路径显示一次 1 秒“Copied 已启动”，用于预热首次可见渲染；该提示没有来源、操作、展开、右键菜单、快速触发或声音，也不触碰剪贴板
- 默认模式显示所有通过来源过滤的视觉提示
- 轻打扰模式按普通短文本、普通长文本、图片、文件和识别类型决定是否显示；自定义只影响视觉提示，不关闭内容识别
- 未识别文本以 50 字符为边界服从普通短/长文本开关；URL、代码和插件等已识别类型只服从对应类型开关，不再叠加普通文本长度开关
- 纯位图和全部为有效图片的文件选择服从“图片”；普通文件、混合选择和无有效图片的文件选择服从“文件”
- 轻打扰筛选发生在视觉去重之前；被筛掉的内容不得占用视觉去重状态
- “仅提醒模式”与上述筛选正交：它只把已经允许显示的完整卡片替换为鼠标旁 1 秒浮标

### 鼠标
- 折叠态悬停卡片 → 暂停自动消失。离开 → 重新计时
- 来源或详情标签溢出 → 悬停卡片 0.6 秒后单次滚到末端、停留并返回；两侧渐隐随滚动方向切换
- 点击右侧操作按钮的完整视觉区域 → 执行当前操作
- 点击预览文本行 → 展开查看全文
- 点击图标、来源信息、卡片其他区域或可见卡片外的透明预留边缘 → 关闭（折叠态）
- 悬停按钮 → 按钮切换为当前快速触发图标（默认 ⌃），提示可键盘触发（离开 100ms 防抖）
- 右键 → 搜索 / 另存为… / 类型专属操作

### 键盘
- 默认在第一次 Control 松开后的 350ms 内再次按下并松开 Control → 触发按钮操作
- 可在设置中改为 Command、Option、Shift 或关闭键盘触发；单击模式作为高级选项
- 从第一次按下到第二次松开之间出现普通按键、其他修饰键、鼠标点击或滚轮 → 立即取消
- 弹窗出现前已按住触发键 → 松开不触发；需完成一次全新手势
- 可录制原生鼠标侧键作为并行触发方式；录制状态允许主动取消

### 自动消失
- 折叠态弹出 3 秒后自动退场
- 展开态不自动退场，收起后恢复折叠态计时
- 新复制内容到达 → 立即替换（500ms 内相同内容仅视觉去重，声音仍逐次反馈）

## 内容展示

卡片结构：`[图标/色块/缩略图] [单行预览文字 + 来源 + 详情] [操作按钮]`。

**预览**：文本单行显示，超出截断。鼠标悬浮预览行 primary 10% 背景叠加提示可点击。点击展开为全文视图：卡片背景、原生可选文本和独立 SwiftUI 按钮分层渲染，宽 360pt、总高最多 300pt；窗口仅在左右和底部保留 16pt 透明阴影边界，顶部与折叠态保持同一位置。正文视口从卡片顶边延伸到底部按钮上方，顶部 12pt、底部 10pt 作为可滚动文本内边距，视觉顶部两角随卡片圆角裁切；短文本自然高度，长文本只在正文区域滚动，不会进入按钮区域。底部按钮无独立背景，使用 macOS 原生 bordered 样式，含「在文本编辑中打开」「收起」和右下角「关闭」，空白区域不响应点击。展开/收起使用全窗口 CIGaussianBlur + alpha 两段式过渡。展开态暂停快速触发监听且不自动关闭，Panel 自动成为 key、正文自动成为 first responder，支持拖选、原生 ⌘C 和右键菜单；收起后恢复快速触发与自动关闭。**来源与详情**：各自保持单行，自然宽度参与卡片 fitting；卡片达到 360pt 后仍溢出时，以 14pt 边缘渐隐和一次往返滚动完整展示，且不创建独立点击区域。来源由“复制自” + App 图标 + 名称组成，详情根据检测类型显示不同格式。

| 检测类型 | 详情格式 |
|----------|----------|
| URL | `链接 · 120字符` |
| 邮箱 | `邮箱` |
| 电话号码 | `电话` |
| 文件路径 | `路径 · 80字符` |
| 日期时间 | `日期 · 今天` / `日期 · 后天` / `日期 · 明天 01:00`（按日历日）|
| 数学表达式 | `公式 · 45字符` |
| 单个汉字 | `汉字` |
| 英文单词（中文界面） | `英文` |
| 代码语言 | `Swift · 120字符` |
| 无检测短文本 | （不显示）|
| 无检测长文本 | `120字符` |
| 图片 | `PNG 图片 · 1920×1080 · 2.5 MB` |
| 文件 | `PDF 文件 · 2.5 MB` |
| 文件夹 | `文件夹 · 128.5 MB` |
| 多文件 | `3个文件` |

### 操作按钮

右侧最多 1 个按钮，按优先级取最高匹配：

| 检测类型 | 按钮 | 行为 |
|----------|:---:|------|
| 本地 JPG/JPEG/PNG 文件 | 压缩 | 非激活方式交给已安装的 Lithe；同时保留右键菜单入口 |
| URL / 文件路径 | 打开 | 浏览器打开 / Finder 定位 |
| 邮箱 | 发邮件 | AppleScript 打开 Mail.app 新邮件 |
| 电话号码 | 拨打 | FaceTime 音频通话 |
| 日期时间 | 日历 | 打开系统日历 |
| 数学表达式 | 计算 | 内联显示 `=` 精确结果或 `≈` 近似结果；成功后按钮变“复制”，失败时无复制按钮 |
| 单个汉字 | 拼音 | 内联显示拼音（带音调），按钮变"复制" |
| 英文单词（中文界面） | 翻译 | 内联显示牛津词典释义，按钮变"复制" |
| 纯文本 | 短文本搜索；长文本另存为 | 搜索引擎打开 / 保存为 TXT |

无检测匹配时，短文本显示搜索按钮，长文本显示另存为按钮。语言类型（代码等）不产生按钮。

## 产品决策

**固定位置** — 屏幕顶部居中。通知型卡片固定比跟随鼠标更可预测。macOS 无全局鼠标位置 API。

**快速触发** — 默认使用 350ms 内双击 Control：位置容易触达，同时比常用于复制、粘贴和设计工具操作的 Command/Option 更少误触。高级用户可改为单击修饰键或鼠标侧键；任何夹杂输入都会取消当前手势。

**权限切换安全** — System Settings 位于前台时，保留 Copied 的逻辑监听状态但暂时移出活动鼠标过滤器；离开后按真实辅助功能权限恢复或关闭。授权成功提示可一键启动新实例，确认成功后才退出旧实例。

**内联结果** — 计算/拼音/翻译在原卡片内展示结果；成功结果的按钮变“复制”。计算失败只显示错误，不提供复制按钮或快速触发。连续体验，不堆叠弹窗。

**类型检测而非内容读取** — 用 pasteboard 类型元数据判断类别，避免 RichText 中的图片表示导致误判。

**Lithe 集成边界** — 仅在剪贴板包含文件 URL、全部文件均为本地普通 JPG/JPEG/PNG 且系统能定位 Lithe 时提供压缩操作。纯位图、混合选择和不支持格式不触发；Lithe 生成结果携带私有标记与请求 ID，Copied 不再次提供压缩入口，并把不同请求视为不同视觉事件。

**菜单栏应用** — Dock 图标对纯后台工具无意义。菜单栏常驻 + 暂停/恢复更精简。

**声音确认** — 声音确认 Copied 已接受一次新的剪贴板写入，不代表弹窗完成显示；播放异步进行，不应延后视觉反馈。暂停、不可读内容和黑名单来源保持无声。

**筛选与提醒形态正交** — 轻打扰模式回答“哪些内容提供视觉提示”，仅提醒模式回答“允许的提示以完整卡片还是浮标呈现”。两者不能用同一个开关或名称混为一体。

**自动消失** — 折叠态默认 3 秒；展开全文视为用户主动进入阅读状态，因此保持显示，收起后恢复计时。

**低依赖** — 仅 Apple 系统框架，无第三方运行时、无数据收集；网络仅用于读取 GitHub Releases 的最新稳定版本，更新仍由用户前往 GitHub 完成。

**插件声明式** — JSON + 正则，不执行代码。插件只从插件根目录下的非符号链接 `.copiedplugin` 文件夹加载，卸载按清单 identifier 精确匹配实际目录，不用 identifier 拼接删除路径。

**响应边界** — 启动后最多 60 秒以 25ms 检查剪贴板变化，首次有效读取或同一不可读写入尝试 3 次后恢复 75ms；有限重试避免来源 App 分阶段写入时被永久跳过。声音在视觉关键路径之外异步播放，系统词典和实体检测器在启动时用固定合成内容预热；无 scheme URL、电话和日期先经过保守的结构与长度预检，明显不可能完整匹配的长正文不会进入系统实体检测器。

**性能熔断** — 超长文本（>100KB）缩减检测范围，劣性能检测器自动禁用；插件检测和文本转换另有 50ms 正则预算及匹配数、输出长度上限。保证 CPU ≈ 0%。

## 本地化

- **跟随系统** — 支持简体中文、繁体中文和英文，使用 macOS 系统语言或单 App 语言设置，不提供 App 内语言开关。
- **简中零变化** — `zh-Hans` 是源语言和最终回退；现有中文文案、标点、间距及窗口尺寸保持不变。
- **内容不翻译** — 只本地化 Copied 自有界面；剪贴板内容、插件元数据、文件名、App 名称和技术标识保持原文。
- **检测与显示解耦** — 日期等输入识别不能依赖界面 Locale；中文年月日会转换为等价 ISO 候选再解析。
- **英文行为收敛** — 英文界面隐藏并跳过英文单词词典翻译，普通英文文本走搜索；拼音及其他检测保持不变，切换语言不修改用户的检测开关。
