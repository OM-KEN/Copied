# Copied 设计规范

## 设计理念

按下 ⌘C，屏幕顶部弹出一张液态玻璃卡片，告诉你复制成功、让你无需鼠标就能操作。3 秒后安静消失。不抢焦点，不打断工作流。

## 视觉

**材质**：macOS 26 原生液态玻璃，半透明，自适应亮暗模式。

**排版**：San Francisco，预览 14pt Medium，辅助信息 12pt Medium。系统色（`.primary` / `.secondary`），自动匹配主题。

**卡片**：32pt 平滑圆角，最大宽 360pt，内容自适应。边缘 primary 15% 描边补深度（自适应亮/暗模式）。

**图标**：SF Symbols 32pt。色值复制时显示 32×32 圆角色块（同色调阴影）。文件显示 64×64 缩略图。

## 动效

**入场**：弹簧弹入，卡片从菜单栏下方放大+飞入+去模糊+淡入，0.2→1 缩放，四属性同步，~550ms，2-3 次微弹跳。

**退场**：淡出+模糊，200ms。干脆利落。

## 交互

### 鼠标
- 悬停卡片 → 暂停自动消失。离开 → 重新计时
- 点击预览文本行 → 展开查看全文
- 点击卡片其他区域 → 立即关闭（折叠态）
- 悬停按钮 → 按钮切换为修饰键图标（默认 ⌘），提示可键盘触发（离开 100ms 防抖）
- 右键 → 搜索 / 另存为… / 类型专属操作

### 键盘
- 按下修饰键（默认 ⌘，可在设置中改为 ⌥/⌃/⇧）→ 按钮高亮（缩小 0.92，图标切换为对应修饰键符号）
- 松开修饰键 → 触发按钮操作
- 修饰键+组合键（如 ⌘V）→ 取消触发，不误操作
- ⌘C 后若修饰键未松 → 按钮不高亮、不触发

### 自动消失
- 弹出 3 秒后自动退场
- 新复制内容到达 → 立即替换（500ms 内相同内容去重）

## 内容展示

卡片结构：`[图标/色块/缩略图] [预览文字 (最多2行) + 来源 + 详情] [操作按钮]`。

**预览**：文本单行显示，超出截断。鼠标悬浮预览行 primary 10% 背景叠加提示可点击。点击展开为全文视图：全宽 ZStack overlay 布局（maxWidth 360），ScrollView 展示完整文本（maxHeight 300，短文本自然高度无滚动，长文本 300pt 内滚动），底部 `.regularMaterial` 毛玻璃按钮栏（含「在文本编辑中打开」和「收起」）。展开/收起全窗口 CIGaussianBlur + alpha 两段式过渡。展开态 ⌘C 复制选中文本，Escape 折叠，点按钮栏空白区关闭弹窗。**来源**："复制自" + App 图标 + 名称。**详情**：根据检测类型显示不同格式。

| 检测类型 | 详情格式 |
|----------|----------|
| URL | `链接 · 120字符` |
| 邮箱 | `邮箱` |
| 电话号码 | `电话` |
| 文件路径 | `路径 · 80字符` |
| 日期时间 | `日期 · 3天后`（相对时间）|
| 数学表达式 | `公式 · 45字符` |
| 单个汉字 | `汉字` |
| 英文单词 | `英文` |
| 代码语言 | `Swift · 120字符` |
| 无检测短文本 | （不显示）|
| 无检测长文本 | `120字符` |
| 图片 | `PNG 图片 · 1920×1080` |
| 文件 | `PDF 文件 · 2.5 MB` |
| 文件夹 | `文件夹 · 128.5 MB` |
| 多文件 | `3个文件` |

### 操作按钮

右侧最多 1 个按钮，按优先级取最高匹配：

| 检测类型 | 按钮 | 行为 |
|----------|:---:|------|
| URL / 文件路径 | 打开 | 浏览器打开 / Finder 定位 |
| 邮箱 | 发邮件 | AppleScript 打开 Mail.app 新邮件 |
| 电话号码 | 拨打 | FaceTime 音频通话 |
| 日期时间 | 日历 | 打开系统日历 |
| 数学表达式 | 计算 | 内联显示 = 结果，按钮变"复制" |
| 单个汉字 | 拼音 | 内联显示拼音（带音调），按钮变"复制" |
| 英文单词 | 翻译 | 内联显示牛津词典释义，按钮变"复制" |
| 纯文本 | 搜索 | 搜索引擎打开 |

无检测匹配时显示搜索按钮。语言类型（代码等）不产生按钮。

## 产品决策

**固定位置** — 屏幕顶部居中。通知型卡片固定比跟随鼠标更可预测。macOS 无全局鼠标位置 API。

**键盘触发** — 修饰键（默认 ⌘）快速触发主操作，无需鼠标。修饰键可在设置中配置为 ⌥/⌃/⇧。目标用户高频使用复制，减少手离开键盘。

**内联结果** — 计算/拼音/翻译在原卡片内展示结果，按钮变"复制"。连续体验，不堆叠弹窗。

**类型检测而非内容读取** — 用 pasteboard 类型元数据判断类别，避免 RichText 中的图片表示导致误判。

**菜单栏应用** — Dock 图标对纯后台工具无意义。菜单栏常驻 + 暂停/恢复更精简。

**自动消失** — 3 秒默认。通知型工具不应强迫用户手动关闭；想看详情悬停即保持。

**零依赖** — 仅 Apple 系统框架，无网络请求，无数据收集。

**插件声明式** — JSON + 正则，不执行代码。安全可审计，一键安装/卸载。

**性能熔断** — 超长文本（>100KB）缩减检测范围，劣性能检测器自动禁用。保证 CPU ≈ 0%。
