# Copied UI 设计规范

> 状态：用于新 UI、首次引导和现有界面调整的视觉与交互基准
>
> 适用平台：macOS 14+；macOS 26+ 使用 Liquid Glass 适配
>
> 更新日期：2026-08-28

## 1. 文档职责

本文定义 Copied 的视觉语言、设计 Token、组件规则和首次引导页规范。

- `DESIGN.md` 继续负责产品行为、检测逻辑和 Toast 交互决策。
- `CLAUDE.md` 继续负责实现约束、窗口机制和工程边界。
- 本文负责回答“一个新界面应该长什么样、如何排版、如何响应状态”。

本文将规则分为两类：

- **现有基准**：来自当前正式 UI，新界面应保持一致。
- **引导页推荐**：为重新设计首次引导而定义，尚未表示当前代码已经实现。

如果视觉规范与无障碍、系统行为或工程安全约束冲突，优先保证系统行为和可访问性。

## 2. 设计原则

### 2.1 原生

优先使用 SwiftUI/AppKit 原生控件、SF Symbols、系统字体和语义色。不要为普通按钮、Toggle、Picker、Alert 或文件面板重画一套跨平台样式。

### 2.2 安静

Copied 是常驻工具，不应通过大面积高饱和色、持续动画或多层玻璃抢占注意力。颜色主要表达状态，玻璃主要表达悬浮层级。

### 2.3 聚焦

一个页面只突出一个主要决定。主操作应始终出现在稳定位置；不要让用户在同一步同时理解权限、插件、搜索引擎和所有高级选项。

### 2.4 自适应

所有文本和颜色必须适配简体中文、繁体中文、英文、浅色和深色模式。系统语义样式不应被转换为固定 Hex 后写回代码。

### 2.5 渐进授权

辅助功能权限只在用户主动选择需要该权限的功能后请求。首次进入不能用系统权限弹窗打断欢迎和基础说明。

## 3. 基础 Token

### 3.1 字体

全部使用 macOS 系统字体，不引入自定义字体文件。

| Token | SwiftUI | 用途 | macOS 参考值 |
|---|---|---|---|
| `type.pageTitle` | `.title.weight(.semibold)` | 引导页主标题 | 22pt / 26pt |
| `type.sectionTitle` | `.title2.weight(.semibold)` | 关于页、紧凑页面标题 | 17pt / 22pt |
| `type.headline` | `.headline` | 卡片标题、Popover 标题 | 13pt Bold / 16pt |
| `type.body` | `.body` | 表单、说明正文 | 13pt Regular / 16pt |
| `type.caption` | `.caption` | 次级说明、错误补充 | 10pt Regular / 13pt |
| `type.preview` | `.system(size: 14, weight: .medium)` | Toast 或引导中的复制预览 | 14pt Medium / 约 17pt |
| `type.metadata` | `.system(size: 12, weight: .medium)` | 来源、类型、快捷操作 | 12pt Medium / 约 15pt |
| `type.identifier` | `.system(size: 10)` | 插件 ID、ContentKind ID | 10pt Regular / 约 12pt |

规则：

- 页面标题最多两行；首选一行。
- 正文不使用 Light、Thin 或 Ultralight。
- 辅助说明使用 `secondary`，不要通过更小于 10pt 的字号弱化。
- 剪贴板内容、App 名、文件名、插件文字保持原文，并允许系统字体回退。
- 不手写字距；SF 系统字体会按字号调整 tracking。

### 3.2 间距

新 UI 使用 4pt 网格。允许的常用间距如下：

| Token | 值 | 用途 |
|---|---:|---|
| `space.1` | 4 | 图标与短标签、紧密元数据 |
| `space.2` | 8 | 同组按钮、正文内部行组 |
| `space.3` | 12 | 卡片内部元素、图标与正文 |
| `space.4` | 16 | 标准内边距、组件之间 |
| `space.5` | 20 | 紧凑区块上下间距 |
| `space.6` | 24 | 页面区块间距 |
| `space.8` | 32 | 页面外边距、大区块间距 |
| `space.10` | 40 | 大页面留白，仅在空间充足时使用 |

规则：

- 优先从表中选值，不新增 5、7、13、18 等一次性间距。
- Form 内部交给 `.formStyle(.grouped)`，不为每一行叠加自定义 padding。
- 未指定的 SwiftUI Stack 间距是上下文自适应值；关键布局必须显式指定。

### 3.3 圆角

| Token | 值 | 用途 |
|---|---:|---|
| `radius.small` | 4 | 文字 Hover 背景 |
| `radius.control` | 8 | 小按钮、色块、选择描边 |
| `radius.icon` | 14 | 64pt App 图标 |
| `radius.media` | 16 | 缩略图、选择卡片、正文内层表面 |
| `radius.toast` | 32 | 标准 Toast 外轮廓 |

圆角默认使用 continuous 风格。不要在同一组件内同时出现三个以上不同圆角。

### 3.4 颜色

基础颜色只使用语义值：

| Token | SwiftUI | 用途 |
|---|---|---|
| `color.primary` | `.primary` | 标题、主要正文 |
| `color.secondary` | `.secondary` | 描述、来源、次级状态 |
| `color.tertiary` | `.tertiary` | ID、弱化图标、禁用提示 |
| `color.tint` | `.tint` | 选中、焦点、主要操作 |
| `color.success` | `.green` | 已授权、更新可用、成功 |
| `color.warning` | `.yellow` | 权限缺失、非阻断警告 |
| `color.destructive` | `.red` | 删除、不可逆操作 |

叠加层：

- 普通 Hover：`Color.primary.opacity(0.10)`。
- 细边框：`.primary.opacity(0.15)`。
- 选中卡片背景：`.tint.opacity(0.08)`。
- 选中卡片描边：`.tint.opacity(0.70)`，1.5pt。
- 禁用整组内容：不透明度 0.5；同时保留系统 `.disabled` 行为。

禁止：

- 为普通正文硬编码黑色或白色。
- 用固定浅灰同时服务浅色和深色模式。
- 用颜色作为唯一状态线索；状态必须同时有文字或图标。

### 3.5 图标

- 使用 SF Symbols；自有品牌只使用 Copied App 图标和菜单栏模板图。
- 图标重量应与相邻文字接近。
- 12pt：按钮内小图标。
- 16pt：来源 App 图标、列表 App 图标。
- 20–24pt：选择卡片、状态插图。
- 32pt：Toast 主类型图标或引导页功能图标。
- 64pt：About 或引导页 App 图标。
- 图标与文字通常使用 4、8 或 12pt 间距。
- 不通过手工 X/Y 偏移修正 SF Symbol；优先使用 frame 和 alignment。

## 4. 表面与层级

### 4.1 标准窗口

设置、首次引导、Alert 和文件选择属于标准可激活窗口：

- 使用系统窗口背景和标题栏。
- 可以成为 key window，并支持完整键盘导航。
- 不使用 Toast 的 `.nonactivatingPanel`。
- 不在整个窗口上覆盖自定义透明材质。

### 4.2 悬浮 Toast

当前 Toast 是 Copied 最强的品牌表面：

- 最大宽度 360pt。
- 内容内边距 16pt。
- 圆角 32pt。
- macOS 26+ 使用 `.glassEffect(in: .rect(cornerRadius: 32))`。
- 旧系统使用 `.ultraThinMaterial`。
- 外轮廓使用 primary 15%、0.8pt 描边。
- 折叠态按固有内容自适应；普通 32pt 图标、整行内容和短 Action 不得为异步更新预留固定宽高，仅真实缩略图保持 64×64pt。
- 后续识别或插件 enrichment 未提供非空图标时，保留 base content 已显示的图标；空展示字段不得让 Toast 主图标消失。
- 已显示的真实缩略图在淡出与模糊退场期间保持不变，只在窗口隐藏后释放。
- 文件大小进度使用数值右侧的条件式 `ProgressView`；完成后进度与间距一起移除，不保留空槽。深色玻璃卡片只反转系统错误绘制为黑色的原生进度环，浅色模式保持系统原样。
- 超长文本展开时先显示 300pt 最大高度的卡片和正文区 loading，再安装原生文本；loading 在亮暗模式下均须可读，Reduce Motion 下保留文案但隐藏旋转动画，布局完成前底栏全部禁用。
- 展开底栏普通左按钮为纯文字“在文本编辑中打开”；预览被截断时仅改为纯文字、prominent 的“在文本编辑中查看全部”，不添加图标或独立截断标签。TextEdit 打开未截断全文。
- 来源与详情标签的自然宽度参与卡片布局，卡片总宽仍不超过 360pt。
- 标签溢出时保持单行并使用 14pt 方向渐隐；悬停卡片后只做一次往返滚动，标签本身不增加点击或滚动命中区。
- 不把 Toast 的大圆角和全玻璃背景复制到普通设置页面。

### 4.3 内容卡片

引导页的选项或预览可以使用内容卡片：

- 圆角 16pt。
- 内边距 16pt。
- 同级卡片间距 12pt。
- 默认背景使用系统次级填充或极轻材质。
- 默认边框为 primary 12–15%、1pt。
- 选中时使用 tint 8% 背景和 tint 70%、1.5pt 描边。
- 每张卡片必须整体可点击，不只让标题或 Radio 命中。
- 不允许玻璃卡片内再嵌套玻璃按钮和玻璃子卡片形成三层折射。

## 5. 控件规范

### 5.1 按钮

| 层级 | 样式 | 使用场景 |
|---|---|---|
| Primary | 系统 prominent；macOS 26 可用 glass prominent | 每页唯一的“继续/完成” |
| Secondary | `.bordered` | 返回、稍后、打开设置 |
| Tertiary | `.borderless` 或 Plain | 清除、移除之外的低优先操作 |
| Destructive | 系统 destructive role 或红色 Borderless | 移除插件、删除黑名单项 |

规则：

- 页面同时最多一个 Primary Button。
- 标准按钮目标高度不低于 28pt；不要用图标的可见边界充当完整点击区。
- 按钮文案用动作动词，例如“继续”“打开系统设置”“完成”。
- Return 触发 Primary；键盘焦点顺序必须与视觉顺序一致。
- 不为普通按钮硬编码白色文字或背景。

### 5.2 Toggle、Picker 和输入框

- 普通开关使用系统 Toggle；设置 Form 内接受默认 checkbox 表现。
- 需要突出开/关状态的列表尾部控件可用 `.toggleStyle(.switch)`。
- 单选项不超过 4 个且需要解释时，使用整体可点击的选择卡片。
- 紧凑枚举值使用 `.pickerStyle(.menu)`。
- 搜索框可以使用 Plain TextField，但必须提供足够外层 padding 和清晰容器。
- 错误说明放在控件下方，使用 Caption + Secondary/Warning；不要只显示红色边框。
- 设置中的折叠分组保留原生展开箭头，但标题到行尾都应可点击；命中区不能覆盖展开后的 Toggle 或其他控件。

### 5.3 状态反馈

| 状态 | 图标 | 颜色 |
|---|---|---|
| 成功/已授权 | `checkmark.circle.fill` | Green |
| 警告/未授权 | `exclamationmark.triangle.fill` | Yellow |
| 更新 | `arrow.up.circle.fill` | Green |
| 处理中 | `arrow.triangle.2.circlepath` 或系统 ProgressView | Secondary/Tint |
| 删除 | `minus.circle.fill` 或 `trash` | Red |

异步操作必须让原按钮进入 disabled/loading 状态，避免同时出现两个“正在处理”的视觉入口。

## 6. 首次引导页推荐规范

> 状态：首次引导仍待重新设计，当前代码未实现。本节只保留布局、动效和无障碍参考，不把具体步骤、文案或设置映射视为现役产品合同。

### 6.1 目标

首次引导只完成三件事：

1. 说明 Copied 在复制后会做什么。
2. 解释当前反馈设置，但不混淆弹窗筛选与提醒形态。
3. 教会用户使用默认快速触发。

搜索引擎、智能识别开关、插件、黑名单和左右键高级手势不进入固定引导流程，它们留在设置中。

### 6.2 窗口

推荐固定内容尺寸：**560×480pt**。

- 标准可激活窗口，系统标题栏。
- 内容尺寸在步骤切换时保持不变，禁止页面间跳动或 Resize。
- 水平页面边距 32pt。
- 顶部页面边距 28–32pt。
- 底部导航区固定高度 64pt。
- 内容过长时只让中间内容区滚动，标题和底部导航保持稳定。
- 窗口打开后置于主屏幕可见区域居中。
- 打开引导时激活 Copied，但不能暂停剪贴板监听。

### 6.3 页面骨架

每页保持相同结构：

```text
┌────────────────────────────────────────────────────────┐
│  页面图标  标题                                         │
│            一至两行说明                                 │
│                                                        │
│              页面主要内容 / 预览                       │
│                                                        │
├────────────────────────────────────────────────────────┤
│  进度                         返回      继续/完成       │
└────────────────────────────────────────────────────────┘
```

推荐尺寸：

- Header 图标：32pt；欢迎页可使用 64pt App 图标。
- 图标与 Header 文字间距：16pt。
- 标题：`type.pageTitle`。
- 标题与说明间距：8pt。
- Header 与主内容间距：24pt。
- 主内容区内部间距：12–16pt。
- 底栏顶部可用系统 Separator；不要加独立大面积材质。
- 底栏按钮间距：8pt，Primary 始终位于右下。

### 6.4 进度

- 固定流程为 4 步。
- 使用 4 个可访问的进度项；不能只依靠颜色表达当前页。
- 推荐视觉：未选中 6×6 圆点，当前项 16×6 Capsule，间距 6。
- 当前项 Tint，其他项 Tertiary。
- VoiceOver 标签使用“第 2 步，共 4 步”。
- 条件权限说明不增加固定进度数量，可在相关页内展开或使用系统 Sheet。

### 6.5 第 1 页：欢迎

目的：建立产品心智，不展示设置清单。

推荐文案：

- 标题：`欢迎使用 Copied`
- 说明：`复制内容后，Copied 会显示轻量提示，并提供打开、搜索、计算等快捷操作。`
- Primary：`开始设置`
- Secondary：`稍后`

视觉：

- Copied App 图标 64×64、圆角 14。
- 可以展示一张静态 Toast 预览；预览必须使用真实 Toast 的 360pt、32pt 圆角、14pt Preview 和 12pt Metadata Token。
- 预览不执行关闭、复制或快速触发，不把真实 Toast Controller 嵌入引导页。
- 不使用大段功能列表、三列卖点或自动轮播。

### 6.6 第 2 页：复制反馈

目的：选择日常复制后看到的反馈。

推荐文案：

- 标题：`选择复制反馈`
- 说明：`以后可以随时在“设置 → 通用”中修改。`

反馈选项与信息架构待重新设计，不在本文固定卡片数量或最终文案。重新设计时必须明确区分：

1. `弹窗模式`：默认模式显示所有视觉提示；轻打扰模式按普通内容和识别类型筛选哪些提示出现。
2. `提醒形态`：仅提醒模式把已经允许显示的完整卡片替换为指针旁短暂确认图标。

不得把两个维度合并成一个名称或开关。仅提醒模式属于高级设置，不应成为完成引导的前置条件。

卡片规则：

- 使用多张选择卡片时等宽横排；英文文案放不下时允许改为竖排。
- 卡片圆角 16、内边距 16、间距 12。
- 图标 24pt，标题 13pt Semibold，说明 11–13pt Secondary。
- 整卡可点击，同时提供明确选中标记。

提示音：

- 卡片下方使用一行 `提示音` Menu Picker。
- 默认 Frog；切换时立即试听。
- 提供 `无`，不在引导中展开 14 个声音为网格或列表。

### 6.7 第 3 页：快速触发

目的：让用户理解默认 Control 双击，而不是要求记忆所有可配置项。

推荐文案：

- 标题：`无需移动指针，也能执行操作`
- 说明：`弹窗出现时，在 350 毫秒内连续按下并松开两次 Control，即可执行右侧按钮。`

视觉：

- 中央显示键帽 `Control ⌃`，配合“两次轻按”的简短动效或两段状态指示。
- 键帽使用系统背景、1pt 语义边框、8pt 圆角，不仿制实体键盘纹理。
- 下方显示当前设置摘要：`Control (⌃) · 双击`。
- 提供低优先级入口 `更改修饰键…`；展开后使用 Menu Picker，不把全部选项永久铺在主页面。
- 可提供 `录制鼠标侧键…`，但它是可选项，不成为继续的前置条件。

权限：

- 用户没有选择鼠标侧键或左右键手势时，不请求辅助功能权限。
- 用户主动录制侧键后，先显示一段原因说明，再由按钮触发系统授权。
- 权限失败不阻止继续完成引导。

### 6.8 第 4 页：完成

目的：给出明确结束，不再添加新设置。

推荐文案：

- 标题：`一切就绪`
- 说明：`Copied 已在菜单栏中运行。复制任意内容即可开始使用。`
- Primary：`完成`
- Secondary：`返回`

摘要内容随重新设计确定；若包含反馈设置，必须分别表达弹窗筛选与提醒形态，不得压缩成一个含义含混的“反馈模式”。

视觉：

- 绿色 `checkmark.circle.fill`，32pt。
- 摘要使用普通系统列表或一张 16pt 圆角内容卡片。
- 不放庆祝粒子、循环动画、营销链接或插件推荐。

### 6.9 跳过、关闭和重新查看

- 欢迎页提供 `稍后`；后续页面允许关闭标准窗口。
- 跳过不应改变尚未确认的设置。
- 完成后记录已完成状态。
- 建议在“关于”页提供 `重新查看新手引导…`，使用户可以找回说明。
- 重新查看时读取当前设置，不重置用户偏好。

## 7. 动效

### 7.1 标准时长

| Token | 时长 | 用途 |
|---|---:|---|
| `motion.fast` | 0.15s | Hover、选中描边、轻量状态变化 |
| `motion.normal` | 0.20s | 淡入淡出、按钮反馈 |
| `motion.page` | 0.24s | 引导步骤切换 |

### 7.2 引导页过渡

- 下一页：旧内容 opacity 1→0，新内容 opacity 0→1，可附带最多 8pt 的水平移动。
- 上一页方向相反。
- 标题、内容和底栏不能分别使用三套弹簧造成视线漂移。
- 选择卡片使用 0.15s ease-in-out。
- 不自动前进；用户选择后仍由“继续”确认。
- 开启 Reduce Motion 时取消位移，仅保留不超过 0.1–0.15s 的淡入淡出，或直接切换。

## 8. 交互与无障碍

- macOS 默认控制目标建议不小于 28×28pt；图标按钮至少提供这一命中框。
- 所有页面支持 Tab、Shift-Tab、Space 和 Return。
- 不使用 Hover 才能发现的必要信息。
- 选择卡片同时暴露 selected 状态和可读标签。
- SF Symbol 需要可访问名称；装饰图标应隐藏于辅助功能树。
- 颜色状态必须同时提供文字或图标。
- Light/Dark、Increase Contrast、Reduce Transparency、Reduce Motion 均需验收。
- 引导窗口不得抢走用户正在编辑文档中的输入，除非这是 App 首次启动后用户明确打开的引导。
- 系统权限弹窗出现和返回后必须刷新权限状态，不显示过期结果。

## 9. 本地化

- 源语言为 `zh-Hans`，同时支持 `en`、`zh-Hant`。
- 页面不可依赖中文文案长度确定固定宽度。
- 英文标题和按钮允许比中文更宽，但 Primary Button 位置保持不变。
- 说明文字允许换行，不通过缩小字体解决溢出。
- 动态内容使用 String Catalog 的插值和复数规则。
- App 名、插件名、文件名、快捷键名称和剪贴板内容保持原文。
- 引导页新增文案必须在同一次实现中补齐三种语言，不能先提交源语言占位。

## 10. 实现约束

- 首次引导使用独立的标准窗口，不复用 `ToastPanel`。
- 不在窗口级监听鼠标坐标来分发 SwiftUI Button 行为。
- 页面状态与持久化设置分离：用户点“继续/完成”后再提交本页选择，避免关闭窗口留下半完成状态。
- 辅助功能权限仍复用现有权限检查和 `GlobalMouseEventCoordinator`，不增加新的 Event Tap。
- Toast 预览只复用视觉 Token 或纯展示组件，不启动真实计时器、快速触发和剪贴板动作。
- 新增图片前先判断 SF Symbols 和现有 App 图标是否足够；不为装饰性插图引入位图资产。
- macOS 26 的 Glass API 必须使用 availability 判断；macOS 14–25 保持可读的系统材质或填充降级。

## 11. 验收清单

### 视觉

- [ ] 窗口在四个固定步骤之间不改变尺寸或位置。
- [ ] Primary Button 始终位于右下同一位置。
- [ ] 页面只出现一个视觉主操作。
- [ ] 所有间距来自 4pt Token 表或系统 Form 默认。
- [ ] 圆角只使用 4、8、14、16、32 中适用的层级。
- [ ] 没有硬编码正文黑/白色。
- [ ] 没有嵌套三层玻璃或大面积装饰渐变。

### 内容

- [ ] 欢迎页能在十秒内说明 Copied 的用途。
- [ ] 固定流程只包含反馈、快速触发和完成。
- [ ] 高级功能不会阻断完成引导。
- [ ] 权限只在用户主动选择相关功能后请求。
- [ ] 跳过不会意外修改用户设置。

### 本地化与无障碍

- [ ] 简中、英文、繁中无截断和重叠。
- [ ] 浅色、深色、高对比度均清晰。
- [ ] Reduce Motion 下没有明显位移动画。
- [ ] Reduce Transparency 下文本仍有足够对比。
- [ ] 全流程可只用键盘完成。
- [ ] VoiceOver 能读出步骤、选中状态、按钮和权限结果。

### 系统版本

- [ ] macOS 14–25 使用正确降级样式。
- [ ] macOS 26+ 的 Liquid Glass 没有灰闪、裁切或重复折射。
- [ ] 标准窗口与 Toast 的激活行为互不干扰。
